// hands-on

Run it yourself.

Windows, no Docker required. Full clean-machine walkthrough is in USER_MANUAL.md in the repo.

STEP 1

One-time setup

:: venv + deps uv venv .venv --python 3.12 uv pip install -r backend\requirements.txt uv pip install torch==2.5.1 torchvision==0.20.1 \ --index-url https://download.pytorch.org/whl/cu121
STEP 2

Start it

:: unzip assets/postgresql.zip first scripts\start_ibvap.bat

Then open localhost:5173 — login: admin / ibvap-admin-2026

STEP 3

Verify it's real

Run the test suite yourself — zone transitions, alert policy, ANPR validation, JWT tampering, audit tamper detection.

.venv\Scripts\python.exe -m pytest backend\tests -q
